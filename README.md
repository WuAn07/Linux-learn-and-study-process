# Linux-learn-and-study-process

> 简单记录了我 Linux 学习的笔记以及一些代码

这是一个记录个人 Linux 学习过程的仓库，主要存放课程笔记和部分练习代码。内容会随着学习进度持续更新，适合作为入门 Linux 的参考资料。

## 📖 内容概览

仓库当前主要包含以下几份笔记文档：

| 文件 | 说明 | 格式 |
|------|------|------|
| `第1节课--基本指令.docx` | Linux 基本指令的学习笔记（初学 Linux 的第一篇笔记） | Word |
| `第2节课--指令与权限.docx` / `.pdf` | 指令与权限的完整笔记（包含第二部分和完整版本） | Word / PDF |
| `第3节课--开发工具.pdf` | Linux 开发工具的学习笔记 | PDF |

> 笔记按学习进度依次整理，后续会继续补充新的课程内容。

## 🗂️ 学习路线参考

结合笔记内容，当前学习路径大致如下：

1. **基本指令**：熟悉 Linux 常用命令与终端操作
2. **指令与权限**：理解 Linux 的权限模型（用户、组、文件权限等）
3. **开发工具**：掌握 Linux 下的开发环境与工具链

## 🚀 如何使用

1. **克隆仓库**
   ```bash
   git clone https://github.com/WuAn07/Linux-learn-and-study-process.git
   ```

2. **查看笔记**
   直接打开对应的 `.docx` 或 `.pdf` 文件即可阅读。

3. **配合代码练习**
   仓库中如有配套代码，可按笔记中的说明进行编译或运行。
